## The Problem

Discrimination against the LGBTQ+ community is horrifically commonplace in the modern day, with devastating consequences on those who aren't able to or don't know how to seek help, including mass deaths, suicides, and isolation. As an LGBTQ+ individual, I have witnessed and been the receiving end of this abuse, and I have come to believe that one of the major causes is information on the LGBTQ+ community is fairly difficult to find, especially when it comes to debunking misinformation about the LGBTQ+ community.

## The Program

This website will intend to act as a hub for LGBTQ+ culture and info, including sourced information debunking the largely religious and antiscientific misinformation, provide more information about lesser-known LGBTQ+ history, and links to organizations and sources that can aid victims, such as the Trevor Project, and the Trans Lifeline.

### Project Steps

1. Set up the Git Repository
2. Create the skeleton of the website 
3. Create a navigation bar that connects with each page
4. Add functional links to the sources to the website with HTML
5. Stylizing the links with CSS and JavaScript so they're easier to see
6. Adding the required information for the Home, Misinformation, History and Help pages
7. Use libraries to set up the base design of the website
8. Edit the design to make it easy to view for the user

### Future Steps

1. Making the website editable for select trusted individuals (a "living" website)
2. Adding more information and sources (more as the website updates and grows)
3. Adding more subpages as the information grows

### Tools Used

Code: HTML, CSS, and JavaScript
Libraries: Material Design, Pure.css
